### AI Knowledge Assistant (RAG)
> Local-first Retrieval-Augmented Generation assistant that answers from private documents with source citations.

<div align="center">
  <img src="https://images.unsplash.com/photo-1677442136019-21780ecad995?w=1000&q=80" width="850" alt="AI Knowledge Assistant"/>
</div>

<br/>

**Overview**  
Ingests PDF, DOCX, Markdown, CSV and TXT. Uses local embeddings + ChromaDB for retrieval and Ollama/Qwen for grounded answers. Supports re-indexing, citation-backed responses and exportable Word/PDF reports.
